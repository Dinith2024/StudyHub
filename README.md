               📌 StudyHub – Smart Notes & To-Do Web App

A simple and powerful productivity web application designed for students.
Manage tasks, write notes, track deadlines, and stay organized - all in one place.

                          ⭐ Core Features
📝 Tasks Management-
Add new tasks,
Edit and delete tasks,
Mark tasks as completed

📁 Notes Management-
Create study notes,
Edit and delete notes

📅 Deadlines-
Automatically highlight overdue tasks in red

🎨 Modern UI-
Designed using Glassmorphism / Neumorphism,
Clean and attractive interface

🔍 Search & Filter-
Quickly find tasks or notes,
Filter by title, category, or completion status

📱 Responsive Design-
Fully responsive,
Works across desktop, tablet, and mobile
